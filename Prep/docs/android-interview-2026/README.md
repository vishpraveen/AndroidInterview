## Conventions

- **Brief GrandMaster**: thesis → mechanism/order → edge cases/API level → production hook (tool/metric/API) → “when wrong” (anti-pattern). Default **≤8 bullets** or **≤120 words** per question; leadership items use a compact STAR instead of mechanism.
- Track mastery with `- [ ]` / `- [x]` on each block, or `<!-- status: draft|solid -->`.
