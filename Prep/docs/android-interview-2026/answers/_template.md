# Answer block template

Paste under each upstream question heading (keep the same number).

```markdown
### N. <!-- paste question title one line -->

- [ ] <!-- status: draft -->

- **Thesis:** …
- **Mechanism / order:** … (lifecycle, thread, pipeline — be exact)
- **Edge cases / API deltas:** … (OEM, death+restore, version skew)
- **Production hook:** … (tool, metric, API name)
- **When wrong:** … (leak, security, footgun)
```

**Leadership / story questions:** replace “Mechanism / order” with **STAR** (one line each: Situation, Task, Action, Result) under the same cap.
